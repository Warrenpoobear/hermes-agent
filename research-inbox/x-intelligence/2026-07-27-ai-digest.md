## Claim

### Item 1 — Anthropic Context Engineering [ROI 5]
Anthropic removed over 80% of Claude Code's system prompt for Opus 5 and Fable 5 with no measurable loss on coding evaluations. The change — termed "unhobbling" — replaces always-on prose constraints with tool schemas, selectively loaded skills, and deferred ToolSearch definitions.

### Item 2 — Cursor Agent Swarm [ROI 4]
A frontier planner (Opus 4.8 or Fable 5) directing cheaper Composer 2.5 worker swarms reached 100% task completion in every configuration tested. Single-model baselines scored 11–77% at the 4-hour mark. Cursor published the codebase (minisqlite) on GitHub.

### Item 3 — Claude Opus 5 ARC-AGI-3 Record [ROI 3]
ARC Prize independently verified Opus 5 at 30.2% on ARC-AGI-3 — nearly 4× the prior record of 7.8% set by GPT-5.6 Sol. Five previously unsolved environments, four at or above human level. Skeptic caveat: maximum reasoning effort setting was not run.

### Item 4 — Benchmark Calibration [ROI 3]
Multiple practitioners note Opus 5 underperforms Fable 5 in extended agentic and multi-step workflows despite strong benchmark scores. Vendor data shows 26% failure on enterprise process automation. Benchmark saturation, contamination, and overfitting are now documented failure modes across frontier model comparisons.

## Why it matters

### Item 1
Hermes skill documents (45 skills) were engineered against earlier-generation model behavior. A large fraction may be compensating for limits that Claude 5 no longer has. Trimming them frees context window, reduces token cost, and may resolve latent instruction conflicts — directly actionable for screener-ops, biotech-screener agent calls, and the PKOS skill layer.

### Item 2
Validates the planner-worker split as a production architecture for Hermes: one frontier model orchestrates intent; cheaper workers execute subtasks. Directly relevant to Hermes v0.19 upgrade planning and biotech-screener agent redesign.

### Item 3
ARC-AGI-3 uses private test sets resistant to the three benchmark failure modes (saturation, contamination, overfitting). A 4× leap with independent verification carries more weight than typical claims. Relevant to calibrating Hermes model upgrade timing.

### Item 4
Calibration guard against over-trusting benchmark scores when routing Hermes production workloads to newer models. Reinforces the 20-cycle clean-run gate before any model upgrade.
