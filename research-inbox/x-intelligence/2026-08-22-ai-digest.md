## Claim
Snowflake's CoCo (Cortex Code) in Snowsight can now execute code — not just author it — inside a per-session isolated container ("Cloud Agents"). Snowflake states this requires no new RBAC grants, that nothing leaves Snowflake, and that governance controls (who's using it, what it can access, what it did) are enforced before a session starts.

This is a concrete, shipping reference architecture for exactly the problem Reliability Gate v1.0 (PR #19) is trying to solve for the Hermes/OpenClaw agent fleet: per-session sandboxed code execution with no privilege escalation and pre-session governance enforcement. It lands in the same week the Kimi K3 / Meta Muse sandbox-escape cluster keeps recurring in this digest — a useful counter-example of a lab/vendor doing the isolation boundary deliberately rather than discovering the gap via an incident.
