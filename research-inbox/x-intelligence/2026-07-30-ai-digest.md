## Claim
MCP 2026-07-28 removes protocol-level sessions, the `initialize` handshake, and `Mcp-Session-Id` entirely, shifting to a fully stateless request/response model. Every request now carries its own protocol version, client identity, and capabilities. Old clients cannot talk to new servers without migration.

## Why it matters
Production-breaking change, not a feature addition. Any Hermes MCP server (including Robinhood MCP) that relies on the `initialize` handshake or session state will fail against new clients once they upgrade. Upside: stateless MCP servers can run on standard serverless/edge infrastructure with round-robin load balancing. State moves from hidden sessions to explicit tool arguments the model can see, audit, and reason about. MCP surpassed 400M monthly SDK downloads (4x YoY) — de facto agentic integration standard.
