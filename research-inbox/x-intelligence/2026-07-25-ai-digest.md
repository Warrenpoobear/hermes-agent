## Claim
Claude Opus 5 (released July 24, 2026) ships a beta API feature allowing tools to be added or removed mid-conversation without invalidating the prompt cache, via `tool_addition` and `tool_removal` content blocks on `role: "system"` messages. Prompt-cache minimum also dropped to 512 tokens (half of Opus 4.8). Automatic safety-classifier fallback beta reroutes blocked requests to a specified fallback model instead of failing outright.

## Why it matters
Hermes agents that cycle through phases (research → edit → verify → report) currently re-bill the full prompt prefix every time the tool list changes. Mid-conversation tool switching preserves the cache across phase transitions, cutting cost and enabling tighter per-phase tool scoping — which also reduces wrong-tool calls. The automatic fallback eliminates silent pipeline failures when a safety classifier fires on an edge-case prompt.

## Claim
DFAH-Bench (arXiv:2607.20491, IBM; ICLR 2026 FinAI workshop) is a replay benchmark measuring observable behavioral instability in financial AI agents. Across 8,127 runs, 10 models: decision determinism and accuracy are not correlated (Spearman r = −0.11, p = 0.63). Introduces DAR (Decision Agreement Rate), TAR (Tool-path Agreement Rate), and the DAR–TAR gap — which identifies agents producing consistent decisions via inconsistent reasoning paths, invisible to outcome-only evaluation.

## Why it matters
The biotech screener's IC framework and PIT-safe backtesting methodology implicitly treat consistent model output as a reliability proxy. DFAH-Bench proves this is structurally wrong. The DAR–TAR gap exposes a failure mode directly relevant to trusting any Hermes agent output in production.

## Underlying source
arXiv:2607.20491: https://arxiv.org/abs/2607.20491 | PyPI: https://pypi.org/project/dfah-bench/ | GitHub: https://github.com/ibm-client-engineering/output-drift-financial-llms | Prior workshop paper (ICLR 2026 FinAI): https://arxiv.org/html/2601.15322

## Verification
IBM Client Engineering preprint + ICLR 2026 FinAI workshop prior work. 8,127 agentic runs across 7 models and 3 financial benchmarks. Open-source code available (`make reproduce-paper`). Not yet major-venue peer-reviewed — confidence capped at medium.

## Potential workflow impact

## Smallest shadow test
